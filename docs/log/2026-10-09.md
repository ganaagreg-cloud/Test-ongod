- Each e2e run is a new device for the owner (limit 2); the login screen's "remove and sign in" is used. Dev database now holds extra `e2e.*` users (the portal e2e does the same)
- Browser file button is English (native); admin bundle has no code splitting; light badge contrast still below AA ([[R-admin-light-contrast]], [[open-questions]] #13)
